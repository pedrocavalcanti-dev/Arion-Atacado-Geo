# Projeto

Arion Atacado Geo é uma camada de inteligência operacional sobre OTRS/CMDB.

## Não substitui

- OTRS
- CMDB
- BI
- relatórios executivos

## Objetivo

Facilitar consulta e exploração diária dos dados:

- Base
- Mapa
- Rankings
- Dashboard/Cockpit
- análise por projeto
- análise por operadora
- análise por ISP
- comparação temporal

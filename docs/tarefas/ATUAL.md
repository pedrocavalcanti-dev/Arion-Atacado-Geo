# Tarefa atual: Refinamento do Dashboard e do Cockpit

Status: concluída

`/dashboard/` é a visão executiva com CMDB real e indicadores demonstrativos
claramente identificados. Chamados, reincidências e série mensal usam a mesma
fonte determinística do Cockpit. O Dashboard mostra a distribuição por operadora,
Top Estados e Top Provedores da CMDB.

`/cockpit/` permanece a ferramenta de exploração, comparação, consultas rápidas
e Saved Views privadas. A exportação está indicada como "Em breve"; a futura
Report Engine deve consumir o mesmo Query Engine. Tickets OTRS ainda não estão
integrados.

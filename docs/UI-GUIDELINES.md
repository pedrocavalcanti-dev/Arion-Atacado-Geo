# UI Guidelines

## Visual

- corporativo
- clean
- premium
- pouco ruído
- Inter/typografia equivalente
- bordas suaves
- sombras discretas
- sem glow exagerado
- sem "card soup"

## Dark / Light

Toda nova funcionalidade deve suportar ambos.

Usar variáveis globais existentes.

## Frontend

HTML/CSS/JS separados.

Preferir componentes existentes.

Não adicionar framework SPA.

## Interação

- animações leves
- loading localizado
- empty states claros
- sem overflow horizontal
- desktop prioritário
